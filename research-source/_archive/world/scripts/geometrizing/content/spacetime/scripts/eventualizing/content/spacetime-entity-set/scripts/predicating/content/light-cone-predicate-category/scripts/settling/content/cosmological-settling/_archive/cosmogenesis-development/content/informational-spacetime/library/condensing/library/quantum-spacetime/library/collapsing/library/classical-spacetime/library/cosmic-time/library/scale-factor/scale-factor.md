**Scale-factor** $a(\tau)$ is the **stage coordinate of the relaxation** — the single number tracking how far classical-spacetime has run toward its [thermalizing](../../../../../../../../../../../../../../../../../../../../../../../../../../../../../informational-spacetime/scripts/condensing/content/quantum-spacetime/scripts/collapsing/content/classical-spacetime/scripts/thermalizing/thermalizing.md) fixed point.
All cosmic distances scale $\propto a$; $a=1$ at the present.

## Generated by the relaxation orbit

The [cosmic-thermalization](../thermalizing/library/thermal-spacetime/library/cosmic-finite-thermalization-algebra/library/thermalization/library/cosmic-thermalization/cosmic-thermalization.md)'s increment-sequence injects the scale-factor history, so the relaxation (thermalization) orbit and $a(\tau)$ are the same object.
Its growth rate $\dot a/a$ is the **hubble-parameter** $H$, and the orbit's per-stage inflation factor $\lambda$ at stage $\tau$ is $H$ there — so $H$ *is* the relaxation rate.
