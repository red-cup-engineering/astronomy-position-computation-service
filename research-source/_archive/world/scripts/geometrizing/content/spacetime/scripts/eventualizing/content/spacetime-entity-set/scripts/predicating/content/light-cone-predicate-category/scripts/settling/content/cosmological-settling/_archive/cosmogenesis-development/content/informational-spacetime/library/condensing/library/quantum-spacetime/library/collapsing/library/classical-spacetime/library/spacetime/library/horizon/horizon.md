A **horizon** — the edge of causal contact: how far the field's signals and relaxation can reach (the particle horizon; the Hubble horizon $c/H$).
It bounds the [observable-universe](../observable-universe/observable-universe.md) — the same kind of boundary a black-hole's local sheaf carries, here at cosmic scale.
