The **metric** $g$ — the base's distance-and-duration structure; in cosmology the FLRW form $ds^2 = -dt^2 + a(\tau)^2\,d\Sigma^2$, scaled by the relaxation stage $a(\tau) =$ [scale-factor](../../../scale-factor/scale-factor.md).
The metric is what [spreading](../../../spreading/spreading.md) (◇) acts on — expansion is the relaxation rescaling the base.
