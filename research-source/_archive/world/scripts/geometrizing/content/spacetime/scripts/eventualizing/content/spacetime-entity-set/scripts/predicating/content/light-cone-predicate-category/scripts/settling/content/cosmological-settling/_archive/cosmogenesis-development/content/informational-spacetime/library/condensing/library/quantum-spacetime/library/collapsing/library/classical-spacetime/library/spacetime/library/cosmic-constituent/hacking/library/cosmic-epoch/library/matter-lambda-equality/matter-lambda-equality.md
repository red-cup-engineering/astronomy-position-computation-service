**Matter–Λ equality** — the redshift $z_c$ where [matter](../../../../../library/matter/matter.md) (□) density crosses [dark-energy](../../../../../library/dark-energy/dark-energy.md) (◇), $(1+z_c)^3=\Omega_\Lambda/\Omega_m$.
In proper terms it is the **□→◇ crossover**: the relaxation passing from constraining-dominated to spreading-dominated (decelerating→accelerating) — the **sign change of the modal balance**, the critical point of the cosmic RG flow.
The cosmos-fact behind the $g(z)$ peak ($0.7<z<1.3$) and RFS's $A(z)$ sign-change.
