**Conflating** is the morphism that collapses the pipeline↔duality identification from *two* assumptions to *one*.

## The relation (verified)

For every substitution the two tropical eigenvalues of the [`cosmic-scott-skeleton`](../cosmic-scott-skeleton/cosmic-scott-skeleton.md) are exact negation-conjugates:

$$\lambda_w^{\min}(w) \;=\; -\,\lambda_w^{\max}(-w),$$

because cycle-means negate ($\min S = -\max(-S)$).
Verified on Fibonacci, Padovan, Tribonacci.

## It IS conflation

Negation on the weight/knowledge axis is exactly **conflation** — the bilattice's De Morgan involution / knowledge-order reversal (predication-categories corpus, `conflation-as-knowledge-axis-reversal`).
So the min-plus reading is *forced* as the **conflation-dual** of the max-plus reading.
The two Hubble pipelines are therefore **conflation-dual readings of one cosmic-scott thermalizing**:

- **CMB** $= \lambda_w^{\min}$ — a single global least-cost fit anchored on the sound horizon (least cost = inf = min-plus); the smaller reading (~67).
- **distance ladder** $= \lambda_w^{\max}$ — an accumulating distance *path* (Cepheid→SN→Hubble-flow), the dominant accumulated path = sup-growth = max-plus; the larger reading (~73).

The assignment is fixed by the observed sign ($\lambda^{\max} \ge \lambda^{\min}$, and $H_0$ *is* $\lambda$, so the larger reading is $\lambda^{\max}$).

## Consequences

Conflation is an **involution**, so the duality is exactly **2-fold** — matching exactly two $H_0$ pipeline families, with no third independent reading.
The gap it produces (the [`duality-gap`](../duality-gap/duality-gap.md)) is the inconsistency-axis content (the bilattice $\top$ / $H^1_{\text{top}}$), tying this reading back to the bigraded diamond's **static fibration axis** — the same $H^1$ the [hubble-tension](../../../../../hubble-tension.md) cell carries.
