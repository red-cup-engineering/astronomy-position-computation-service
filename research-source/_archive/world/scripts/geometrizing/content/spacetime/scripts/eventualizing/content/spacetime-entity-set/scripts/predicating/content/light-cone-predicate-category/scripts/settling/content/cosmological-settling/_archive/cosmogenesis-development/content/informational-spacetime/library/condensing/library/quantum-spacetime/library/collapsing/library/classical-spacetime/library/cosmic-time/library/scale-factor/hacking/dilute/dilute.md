**Dilute** — [spreading](../../../../../spreading/spreading.md) thins each [constituent](../../../../../spacetime/library/cosmic-constituent/cosmic-constituent.md)'s charge by its modal character $w$: $\rho\propto a^{-3(1+w)}$.
The differing rates (matter $a^{-3}$ □, radiation $a^{-4}$, Λ const ◇) are why which constituent dominates changes with stage.
