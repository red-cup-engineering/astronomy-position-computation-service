A **void** — a vast under-dense region where spreading (◇) locally wins over constraining (□): [thermalizing](../../../../../../../../../../../../../../../../../../../../../../../../../../../../../informational-spacetime/scripts/condensing/content/quantum-spacetime/scripts/collapsing/content/classical-spacetime/scripts/thermalizing/thermalizing.md) never begins there, so it is the **least-thermalized** structure — pure classical, the field still relaxing outward.
It is the complement of the thermal pockets, the space the [cosmic-web](../cosmic-web/cosmic-web.md)'s sheets and [filaments](../filament/filament.md) bound.
(Distinct from the framework's articulation-void.)
