**The Hubble tension** — early-universe (CMB) and late-universe (distance-ladder) inferences of $H_0$ disagree (~67 vs ~73 km/s/Mpc).

It is an **$H^1$ obstruction in the study, not a contradiction in the cosmos** (see [cosmos](../../../../../../../classical-spacetime.md), [cosmology](../../cosmology.md)): two pipelines thermalize the *same* cosmos-cell $H(z)$ and fail to glue.
Its value across redshift is the predecessor papers' sufficiency gap $g(z)$ — see [`h1-equals-g-of-z`](../../docs/dev/h1-equals-g-of-z.md).

## Stage-offset reading

If $H = \dot a/a$ (a growth rate) is, by [[residuation-forces-a-spiral]], the [[thermalization-spiral]] inflation factor λ of [[cosmic-thermalization]] read **at a stage** (see [`hubble-constant`](../../hubble-constant.md)), then both pipelines read the **one cosmic-scott spiral** (κ=ω, golden **φ ≈ 1.618**; the regime→Pisot grounding is the [grounding note](../../../../../../../docs/dev/cosmic-regimes-as-nbonacci-rg-flow.md)) at two stages τ:

- **CMB** — a κ=ω join thermalized in the past, propagated forward by [`flow`](../flow/flow.md): **early scott**, stage τ_CMB.
- **distance ladder** — read at the present [`observer-stage`](../../../../../../../observer-stage/observer-stage.md): **later scott**, stage τ_now.

"~67 vs ~73" is a stage offset along that one φ-spiral.
The two pipelines form a [[multi-observer-system]] `V: {early, late} → Thermalizations`, which permits disagreement; the disagreement persists because a cosmic-scott thermalizing is **unconverged** (κ=ω: the ω-limit is approached, not reached), so two distinct stages of one still-running spiral genuinely differ.

## The tension is the fixed signature of being not-yet-thermal

The disagreement is removed only when thermalizing reaches its fixed point — which is **thermalizing** itself ([`thermalizing`](../../../../../../../../../../../../../../../../../../../../../../../../../../../../../../../../../../../informational-spacetime/scripts/condensing/content/quantum-spacetime/scripts/collapsing/content/classical-spacetime/scripts/thermalizing/thermalizing.md), scott→finite, φ→ρ), the cosmos's terminal stage = **heat death**.
Thermalizing is a single stage-jump, not a gradual relaxation, so the tension does not shrink over cosmic time: it is the **fixed signature of the cosmos being in the scott stage**.
An observer measures a nonzero tension because an observer exists only in the not-yet-thermal regime ([`observer-stage`](../../../../../../../observer-stage/observer-stage.md)).
