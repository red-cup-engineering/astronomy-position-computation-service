**Amplitude** is the cell of quantum-spacetime: the oriented triple ([quantum](../quantum/quantum.md), [mode](../mode/mode.md), quantum) — the kernel's value-free predication cell `(subject, predicate, object)`.

It carries **no value**.
The kernel cell schema *forbids* a value field, because a definite value "would make cell-identity valuation-dependent and collapse the fibration."
That value-freedom **is** superposition: an amplitude is a relation held without a definite outcome.

Value enters only when [collapsing](../../../../../../../../../../../../../../../../../../../../../../../informational-spacetime/scripts/condensing/content/quantum-spacetime/scripts/collapsing/collapsing.md) measures the amplitude into classical-spacetime — the quantum → classical seam.
