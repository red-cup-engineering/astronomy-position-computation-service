**Angular-diameter distance** $D_A(z)$ relates a physical transverse size to its observed angular size at redshift $z$.
It is the geometry-probe observable; together with [H(z)](../hubble-parameter/hubble-parameter.md) it spans the $(H, D_A)$ plane the predecessor papers project pipelines into to measure the residuated/overlap gap.
A cosmology cell with $D_A(z)$ as subject is thermal by each pipeline with its own covariance.
