**Cosmic-epoch** — the history as objects: the **stages τ of the relaxation orbit**, each a [redshift](../../../../../../scale-factor/library/redshift/redshift.md) range of the [scale-factor](../../../../../../scale-factor/scale-factor.md) history.
In order: [big-bang](library/big-bang/big-bang.md) (collapsing: quantum→classical) → [inflation](library/inflation/inflation.md) → [nucleosynthesis](library/nucleosynthesis/nucleosynthesis.md) → [matter-radiation-equality](library/matter-radiation-equality/matter-radiation-equality.md) → [recombination](library/recombination/recombination.md) (last-scattering, the [CMB](../cosmic-signal/library/cmb/cmb.md)) → [reionization](library/reionization/reionization.md) → [structure-formation](library/structure-formation/structure-formation.md) → [matter-lambda-equality](library/matter-lambda-equality/matter-lambda-equality.md) (the □→◇ crossover) → [heat-death](library/heat-death/heat-death.md) (thermalizing complete).
Each is a milestone of the one relaxation, from the big bang toward the thermal fixed point.
