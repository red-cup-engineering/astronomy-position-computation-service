**Redshift** $z = 1/a - 1$ is the **lookback index** into the relaxation: it reads the [scale-factor](../../scale-factor.md) — the relaxation stage — at light's emission, from that light received now ($a=1$ now ⟹ $z=0$; earlier stages have smaller $a$, larger $z$).
Observing at redshift $z$ reads an earlier **stage τ** of the relaxation orbit; it is how the stages are addressed (the hubble-tension stage-offset reads $\tau_{\rm CMB}$ at $z\approx1100$ vs $\tau_{\rm now}$ at $z=0$ on the one orbit).
