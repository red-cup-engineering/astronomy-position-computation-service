A **cosmic-horizon is the ⊥-ceiling on [observing](../../observing.md)** — the boundary of the cells observing can lift off bottom.
Inside it, a cell can carry any of the four charges (⊥/t/f/⊤): observing has reached it and can write a value.
Outside it, every cell stays at **⊥**: no signal has reached the observer, so observing has nothing to seed.
The horizon is therefore a property of the *observer* (a cell of the field, with finite reach), never of the field — cells on either side are identical, and two observers at the same [cosmic-time](../../../cosmic-time/cosmic-time.md) but different locations have different horizons centered on different events.
There is nothing *at* the horizon; it is the reach-limit of `collapsing`-from-inside, not a barrier in the substrate.

## Two horizons, set by cosmic-time and the constituents

- **Particle horizon** — the boundary of cells from which a signal *could ever have* reached the observer in the cosmic-time elapsed so far.
  The thermalizing has run only finitely many stages, so only finitely far a signal has propagated; beyond that, ⊥ — never yet recognized.
  The particle horizon is what bounds the [observable-universe](../../../spacetime/library/observable-universe/observable-universe.md).
- **Event horizon** — the boundary of cells from which a signal could *ever* reach the observer in the future.
  Beyond it the charge stays ⊥ permanently.
  This boundary is finite precisely because [dark-energy](../../../spacetime/library/cosmic-constituent/library/dark-energy/dark-energy.md) — the invariant ◇ of the relaxation — accelerates the expansion past the rate any signal can climb: spreading outruns propagation, and the cells it carries away can never be observed.

## The horizon is the ⊥/charged frontier

The [bit](../../../../../../../../../../../marking/library/bit/bit.md)'s four charges make the horizon exact: it is the frontier between the region where observing can lift a cell off ⊥ and the region where it cannot.
So it is the same boundary as the observer's reach — the ultimate selection limit of an [observer-instrument](../observer-instrument/observer-instrument.md), prior to any instrumental cut.
Crossing it (as cosmic-time advances, or as accelerating expansion withdraws a cell) is a smooth lift of one cell's charge off ⊥, or its return to ⊥ — not an event in the field.
