**Cool** — as [spreading](../../../../../spreading/spreading.md) (◇) drives the relaxation (a grows), the charge-intensity (temperature) drops $T\propto1/a$.
Cooling is spreading thinning the charge per stage; its thresholds trigger every [epoch](../../../../../spacetime/library/cosmic-constituent/hacking/library/cosmic-epoch/cosmic-epoch.md) transition (nucleosynthesis, recombination happen at threshold temperatures).
