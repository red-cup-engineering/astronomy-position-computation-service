**Cosmic-structure** is **local thermalization** inside classical-spacetime.
The field is *globally* still relaxing — [spreading](../spreading/spreading.md) ∘ [constraining](../constraining/constraining.md) have not reached their global fixed point.
But where constraining (□, gravity) locally wins over spreading (◇), [thermalizing](../../../../../../../../../../../../../../../../../../../../../../../../../../../informational-spacetime/scripts/condensing/content/quantum-spacetime/scripts/collapsing/content/classical-spacetime/scripts/thermalizing/thermalizing.md) runs to completion *in that region*: a **local sheaf**, H¹=0 locally, inside the not-yet-thermal whole.
Structure is exactly those pockets.

The spectrum is **degree of local thermalization** — how far thermalizing has locally run (how much □ has beaten ◇):

[void](library/void/void.md) (◇ wins; no thermalizing) → [cosmic-web](library/cosmic-web/cosmic-web.md) (first coarse thermalizing) → [filament](library/filament/filament.md) → [galaxy-cluster](library/galaxy-cluster/galaxy-cluster.md) → [halo](library/halo/halo.md) → [galaxy](library/galaxy/galaxy.md) → [star](library/star/star.md) (local thermalizing *held mid-orbit* by fusion) → [black-hole](library/black-hole/black-hole.md) (thermalizing locally complete).

So a black-hole is a pocket of **thermal-spacetime** (the κ<ω sheaf) reached early, inside the still-classical whole; a void is pure classical (◇-dominated); a star is the in-between — thermalizing *pinned* at the [balancing](../balancing/balancing.md) fixed point, its trajectory toward the endpoint being [stellar-evolution](library/star/library/stellar-evolution/stellar-evolution.md).
Generated by constraining (gravity) / [cluster](../spacetime/library/cosmic-constituent/hacking/library/cluster/cluster.md); particular structures are studied downstream by astronomy.
