**Realizing fills the open object-slot of a bit**, driving it from potential to active — the predication-monad multiplication (μ).
It **is** the kernel's `saturate` (`active/voidmath-kernel/articulating/library/category/saturating/scripts/saturate.mjs`):

$$ \mathrm{saturate}([\,\text{carrier},[\,\text{tokenSlot},\text{claimSlot}\,]\,]) \;=\; [\,\text{carrier},[\,[\text{token}],\text{claimSlot}\,]\,], $$

depositing the carrier's token into the empty token-slot (and a no-op if it is already filled).
A potential bit becomes active: the object is now provided.

## Realizing structurally cannot complete the bit

Saturate destructures only the token from the carrier; it **never touches the claim-slot**.
Filling the claim-slot would identify the concept with the object — the concept-horse collapse Frege's distinction forbids — so the operation is *built* to leave it open.
The claim is the **residue**: the content the object-providing monad provably cannot reach.
It is always non-empty; that non-emptiness is exactly this field's $H^1 \neq 0$.

This is not a limitation to apologize for — it is the engine of the descent.
Because realizing delivers the object but never the meaning, there is always something left open, and that leftover is precisely the input the next generator ([condensing](../../../../../../../../../../../../../../../../../../../informational-spacetime/scripts/condensing/condensing.md)) consumes.
The aperiodic regime needs the outside because its own multiplication cannot close itself.

## What realizing delivers

Realizing provides the *signal* — a definite token in a definite slot — and never the *meaning*.
That is the whole content of the engineering layer of communication: a symbol acquires a value, while what the symbol is *about* is bracketed.
The bracketed part is the semantic residue [condensing](../../../../../../../../../../../../../../../../../../../informational-spacetime/scripts/condensing/condensing.md) carries one regime down.
Realizing realizes the signal; the meaning descends.
