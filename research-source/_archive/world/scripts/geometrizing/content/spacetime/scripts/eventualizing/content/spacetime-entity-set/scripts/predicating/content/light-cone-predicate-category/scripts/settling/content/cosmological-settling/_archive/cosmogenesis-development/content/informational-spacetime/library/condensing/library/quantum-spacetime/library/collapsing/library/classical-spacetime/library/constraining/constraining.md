**Constraining** is the backward modal generator (□) on the knowledge order: it lowers each cell's charge to the knowledge-**meet** across the valuation.
Right adjoint of [spreading](../spreading/spreading.md) (◇ ⊣ □).
It **is** the kernel's `necessitate-knowledge`.

## The derivation

Lowering every cell's charge to the meet of the valuation keeps only **what must hold** — the conserved constraint the spread must respect.
`spreading ∘ constraining` iterated to a fixed point is therefore relaxation to the **maximum-entropy state consistent with the constraints**, which [thermalizing](../../../../../../../../../../../../../../../../../../../../../../../../../../../informational-spacetime/scripts/condensing/content/quantum-spacetime/scripts/collapsing/content/classical-spacetime/scripts/thermalizing/thermalizing.md) glues into the equilibrium sheaf.
