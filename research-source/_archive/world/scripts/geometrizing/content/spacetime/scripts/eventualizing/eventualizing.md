# eventualizing

Generates [spacetime-entity-set](content/spacetime-entity-set/spacetime-entity-set.md) from [`spacetime`](../../spacetime.md): take the underlying point set of the manifold as the entity set E_cos, each element a cosmic event. It carries a causal partial order ≼ (future light cone), a proper-time metric along worldlines, and (in FLRW) a cosmic-time projection — the structure the settling reindexes over.
